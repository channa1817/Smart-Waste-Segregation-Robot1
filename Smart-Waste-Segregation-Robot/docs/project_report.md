# 📘 Smart Waste Segregation Robot

## 🧠 Introduction
This project aims to automate waste segregation using sensors and AI.

---

## 🎯 Objectives
- Reduce manual waste handling
- Improve recycling efficiency
- Enable smart waste management

---

## ⚙️ Methodology
- Detect object using IR sensor
- Identify metal using proximity sensor
- Detect wet/dry using soil sensor
- Use AI model for advanced classification
- Rotate bin using stepper motor
- Dump waste using servo

---

## 📊 Results
- Real-time waste classification achieved
- Efficient automation using conveyor system
