# 🔌 Wiring Details

## 🧠 Arduino Connections

### Sensors
- IR Sensor → D5
- Proximity Sensor → D6
- Soil Sensor → A0

### Actuators
- Servo Motor → D7
- Buzzer → D12

### Stepper Motor (ULN2003)
- IN1 → D8
- IN2 → D9
- IN3 → D10
- IN4 → D11

### Conveyor Motor (L298N)
- IN3 → D2
- IN4 → D3

---

## ⚠️ Notes
- Common ground is mandatory
- Use external power for motors
